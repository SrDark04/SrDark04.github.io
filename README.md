# ⚡ Portafolio Profesional — Roger Mauricio Durán Guacaneme (@SrDark04)

> Sitio web profesional e interactivo desarrollado en **React**, **Vite** y **Tailwind CSS**, optimizado para el perfil de Ingeniero de Sistemas especializado en Backend, Arquitectura de Software, Ciberseguridad, Redes y Automatización DevOps.

## 🎨 Paleta de Color & Diseño
- **Tema Oscuro de Alto Contraste:** Inspirado en terminales modernas y diseño de vanguardia.
- **Azul Aguamarina (Neon Cyan / Teal):** `#00f5d4` / `#00f2fe` / `#22d3ee`
- **Lila (Neon Lilac / Violet):** `#b388ff` / `#c084fc` / `#a855f7`

## 🚀 Características Principales
1. **Selector Inteligente de Hoja de Vida (CV):**
   - Modal interactivo para descargar o visualizar en PDF las 3 variantes especializadas:
     - 🏗️ *Arquitectura & Backend* (Java 21, Spring Boot, Hexagonal, Microservicios).
     - 🛡️ *Ciberseguridad & Redes* (Wireshark, Análisis PCAP, IA para Incident Response).
     - ⚙️ *DevOps & Automatización* (Docker, GitHub Actions, Azure DevOps, Arch Linux Kernel).
2. **Terminal Interactiva de Arch Linux:**
   - Emulador interactivo con comandos: `help`, `whoami`, `skills`, `projects`, `certs`, `arch`, `contact`, `clear`.
   - Botones de acceso rápido para reclutadores y visitantes técnicos.
3. **Pilar de Tres Especializaciones:**
   - Desglose detallado de Arquitectura Backend, Ciberseguridad/Redes y DevOps/Infraestructura.
4. **Showcase de Proyectos Galardonados:**
   - 🥈 *ZEAL – Plataforma Web de Retención y Propósito Laboral* (2º Lugar Feria de Ideas Inspiradoras).
   - 🥈 *Sistema Distribuido DOSW de Torneos Deportivos* (2º Lugar 4ª Edición DOSW ECI).
   - 🔬 *Sistema Inteligente de Priorización de Tokens y Mitigación con IA* (Nivel Posgrado).
   - 🐧 *Infraestructura y Automatización de Kernel en Arch Linux*.
   - Modal de arquitectura técnica para cada proyecto con enlaces directos a repositorios.
5. **Certificados y Acreditaciones Oficiales:**
   - Visualización directa de diplomas y certificados en PDF (Ideas Inspiradoras, Politécnico de Colombia, Platzi, Superintendencia de Industria y Comercio SIC, Cisco).
6. **Formulario y Acciones Rápidas de Contacto:**
   - Copiado de correo electrónico al portapapeles con animación de confeti.
   - Enlaces directos a WhatsApp, LinkedIn y GitHub.
7. **Despliegue Continuo (CI/CD) a GitHub Pages:**
   - Flujo de GitHub Actions en `.github/workflows/deploy.yml` que compila y publica automáticamente ante cada commit en la rama `main`.

## 🛠️ Ejecución Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/SrDark04/SrDark04.github.io.git
cd SrDark04.github.io

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev

# 4. Construir para producción
npm run build

# 5. Vista previa local del build
npm run preview
```
